# Selected Academic Projects

These descriptions summarize coursework and project experience. This page does not contain application source or claim that a public code release exists.

## Markov Text Generator

**Technology:** Python and NumPy

Implemented text processing, n-gram transition matrices, and weighted random sampling to generate text from literature inputs. The project explores probabilistic generation and limitations in sentence coherence.

A Markov model is distinct from the LLM-assisted development tools I use for other work.

## OpenLead Workflow and Monitoring Dashboard

**Technology:** JavaScript and Figma

Implemented lead filtering and state-based tracking for a workflow dashboard. A Figma prototype and survey supported user evaluation work. Preparing evaluation materials is distinct from reporting validated usability results.

[View the Figma prototype](https://www.figma.com/proto/dYdwDGbzndbyZhcKV3Tk3K/Open-Lead-High-Fidelity-Prototype?node-id=4002-57&starting-point-node-id=4002%3A57)

## Real Estate Android Application

**Technology:** Java, Kotlin, and Firebase

Built a modular Android app to manage and display 150+ property listings. Integrated Firebase Authentication for 25+ development test accounts and Firestore synchronization for listing updates.
