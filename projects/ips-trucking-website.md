# IPS Trucking Website

**Project type:** Transportation website preview  
**View:** https://ips-driven-web.lovable.app/

## Purpose

Present IPS Trucking's services and help customers organize the information needed for a freight inquiry: contact details, route, shipment requirements, optional files, and consent.

## Implementation

React, TypeScript, TanStack Start, Tailwind CSS, React Hook Form, and Zod. The quote interface is organized into five steps and includes validation, attachment checks, and visible submission states.

I worked on the website's branding, photography presentation, responsive layouts, and delivery through GitHub and hosting previews.

## Current status

The website has a published preview. Its quote and contact delivery endpoints are not configured in the current source, so it should not be represented as a live inquiry-delivery integration.

The preview's hostname retains the original project identifier. The application repository is named `ips-trucking-website` and is maintained privately.
